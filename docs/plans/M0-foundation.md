# M0 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backend and frontend skeletons that build, test and run against the local MySQL, with the shared error format and CI in place.

**Architecture:**
- **Backend:** a Spring Boot app generated by Spring Initializr, with the `common` package from the main plan.
- **Frontend:** a Vite React app with Mantine, routing, Query and i18n set up.
- **CI:** GitHub Actions runs both builds and their tests.

**Tech Stack, Global Constraints, conventions:** [00-main-plan.md](00-main-plan.md)

**Spec:** `docs/superpowers/specs/2026-10-28-sports-league-app-design.md` (sections 7–9)

### Task 1: Local databases, backend skeleton, error format

**Files:**
- Create: `.gitignore`, `docs/dev/mysql-setup.sql`, `backend/` (generated)
- Create: `backend/src/main/resources/application.yml`, `backend/src/test/resources/application-test.yml`
- Create: `backend/src/main/java/com/sportsapp/common/{BaseEntity,ApiException,ApiExceptionHandler,Visibility}.java`
- Test: `backend/src/test/java/com/sportsapp/common/{IntegrationTest,DatabaseSmokeTest,ApiExceptionHandlerTest}.java`

**Interfaces:**
- Produces: `BaseEntity`, `ApiException`, `ApiExceptionHandler` and `Visibility`, exactly as described in the main plan's `common` section.
- Produces: `IntegrationTest`, with `protected MockMvc mvc`, `protected JdbcClient jdbc` and `protected JsonMapper json` (Jackson 3; use whatever mapper bean Boot 4 exposes), plus the truncation behaviour from the main plan.

- [ ] **Step 1: Write `docs/dev/mysql-setup.sql`, plus a root `.gitignore`** (`node_modules/`, `dist/`, `.DS_Store`, `backend/target/`, `backend/src/main/resources/static/`, `.idea/`).

```sql
CREATE DATABASE IF NOT EXISTS sportsapp CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE DATABASE IF NOT EXISTS sportsapp_test CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE USER IF NOT EXISTS 'sportsapp'@'localhost' IDENTIFIED BY 'sportsapp';
GRANT ALL PRIVILEGES ON sportsapp.* TO 'sportsapp'@'localhost';
GRANT ALL PRIVILEGES ON sportsapp_test.* TO 'sportsapp'@'localhost';
```

- [ ] **Step 2: Ask the user to run it.** It needs their MySQL root password: `! /usr/local/mysql/bin/mysql -u root -p < docs/dev/mysql-setup.sql`.
  - Then verify: `/usr/local/mysql/bin/mysql -u sportsapp -psportsapp -e "show databases"` lists both databases.

- [ ] **Step 3: Generate the backend.**

```bash
curl -s https://start.spring.io/starter.zip -d type=maven-project -d language=java \
  -d bootVersion=4.1.2 -d javaVersion=25 -d groupId=com.sportsapp -d artifactId=backend \
  -d name=backend -d packageName=com.sportsapp \
  -d dependencies=web,data-jpa,validation,security,oauth2-resource-server,flyway,mysql \
  -o backend.zip && unzip -q backend.zip -d backend && rm backend.zip
```

  - Then add `org.springdoc:springdoc-openapi-starter-webmvc-ui:3.2.0` to `pom.xml`.
  - If Initializr rejects `4.1.2`, use the newest `4.1.x` it offers and note it in the commit.

- [ ] **Step 4: Write the configuration.**

`application.yml`:
```yaml
spring:
  application.name: sportsapp
  datasource:
    url: ${DB_URL:jdbc:mysql://localhost:3306/sportsapp}
```

`application-test.yml`:
```yaml
spring.datasource.url: ${TEST_DB_URL:jdbc:mysql://localhost:3306/sportsapp_test}
```

  - Security auto-config will lock every endpoint until M1 adds `SecurityConfig`. That's expected.

- [ ] **Step 5: Write the failing tests.**

`ApiExceptionHandlerTest` is a plain unit test. It uses `MockMvcBuilders.standaloneSetup(new ProbeController()).setControllerAdvice(new ApiExceptionHandler())`, where `ProbeController` is a static nested `@RestController` in the test.

```java
@Test void apiExceptionBecomesProblemWithCode() throws Exception {
  mvc.perform(get("/probe/conflict")) // throws ApiException.conflict("TEAMS_LOCKED")
     .andExpect(status().isConflict())
     .andExpect(jsonPath("$.status").value(409))
     .andExpect(jsonPath("$.code").value("TEAMS_LOCKED"));
}
@Test void notFound() // GET /probe/missing throws ApiException.notFound() → 404, $.code "NOT_FOUND"
@Test void beanValidationBecomesValidationCode() throws Exception {
  mvc.perform(post("/probe/body").contentType(APPLICATION_JSON).content("{\"name\":\"\"}"))
     .andExpect(status().isBadRequest())
     .andExpect(jsonPath("$.code").value("VALIDATION"))
     .andExpect(jsonPath("$.errors.name").value("NotBlank"));
}
@Test void optimisticLockBecomesStale() // GET /probe/stale throws new ObjectOptimisticLockingFailureException("X", 1) → 409, $.code "STALE"
```

`DatabaseSmokeTest extends IntegrationTest`:
```java
@Test void usesTestDatabase() {
  assertThat(jdbc.sql("SELECT DATABASE()").query(String.class).single()).isEqualTo("sportsapp_test");
}
```

- [ ] **Step 6:** Run `cd backend && ./mvnw -q test`. Expected: compilation FAIL, because the `common` classes don't exist yet.

- [ ] **Step 7: Implement the `common` classes and `IntegrationTest`.**
  - `BaseEntity`: `@MappedSuperclass`, `@Id @UuidGenerator(style = VERSION_7) UUID id`, `@CreationTimestamp @Column(updatable = false) Instant createdAt`.
  - `ApiExceptionHandler` builds `ProblemDetail.forStatus(status)` with `setProperty("code", …)`. The validation branch adds `setProperty("errors", Map<field, constraintSimpleName>)`, taken from `FieldError.getCode()`.
  - `IntegrationTest` truncation, in `@BeforeEach`:
    - check that `SELECT DATABASE()` ends with `_test`, otherwise throw `IllegalStateException`;
    - list the tables with `SELECT table_name FROM information_schema.tables WHERE table_schema = DATABASE() AND table_name <> 'flyway_schema_history'`;
    - run `SET FOREIGN_KEY_CHECKS=0`, `TRUNCATE` each table, then `SET FOREIGN_KEY_CHECKS=1`.

- [ ] **Step 8:** Run `./mvnw -q test`. Expected: PASS (5 tests).

- [ ] **Step 9:** Commit: `git add .gitignore docs/dev backend && git commit -m "chore: backend skeleton, local MySQL setup, problem-detail errors"`

- [ ] **Step 2: Write the failing locale test.**

```ts
import en from './en.json'; import me from './me.json'
const flat = (o: object, p = ''): Record<string, unknown> => Object.entries(o).reduce((acc, [k, v]) =>
  ({ ...acc, ...(v && typeof v === 'object' ? flat(v, `${p}${k}.`) : { [`${p}${k}`]: v }) }), {})
test('me and en have the same keys', () => expect(Object.keys(flat(me)).sort()).toEqual(Object.keys(flat(en)).sort()))
test('no empty strings', () => [flat(me), flat(en)].forEach(m => Object.values(m).forEach(v => expect(v).not.toBe(''))))
```

- [ ] **Step 4: Implement the app shell.**
